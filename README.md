# مساحة هدوء | Calm Space

تطبيق ويب عربي RTL للعافية الرقمية: يساعدك على ملاحظة ضغطك اليومي، تدوين أفكارك، وتجربة أدوات بسيطة للتهدئة. الواجهة تستخدم HTML وCSS وJavaScript حديثاً، وتحفظ بيانات النسخة التجريبية محلياً على جهازك.

## التشغيل

افتح `index.html` في متصفح حديث، أو شغّله عبر خادم ملفات ثابت محلي إذا أردت تجربة موثوقة للخطوط والصوت. لا يحتاج المشروع إلى بناء أو تثبيت حزم. تعتمد الرسوم البيانية على Chart.js عبر CDN، وتعمل بقية الوظائف محلياً عند تعذّر تحميله.

## الخصائص

- تقييم يومي لمستوى التوتر والطاقة ومصادر الضغط، مع إرشادات عامة غير تشخيصية.
- بطاقات تفاعلية لفهم مصادر ضغط العمل وحفظ المفضلات.
- تمارين تنفّس، مؤقت استراحة، كتابة الأفكار، الامتنان، ترتيب الأولويات، وصوت هادئ اختياري مولّد محلياً.
- دفتر يوميات قابل للإضافة والتعديل والحذف.
- لوحة إحصائيات ورسوم لتتبّع التقييمات ومصادر الضغط.
- تأمل ذاتي، ملف محلي، مظهر فاتح/داكن، واستيراد/تصدير/حذف البيانات.

## الخصوصية والسلامة

لا يتصل التطبيق بخادم ولا ينفّذ تسجيل دخول؛ الاسم والإعدادات وكل السجلات تحفظ في `localStorage` على الجهاز الحالي. لا تخزّن معلومات حساسة في النسخة التجريبية. يمكن استبدال حدّ التخزين في `app.js` بمستودع Firebase أو Supabase أو SQL لاحقاً؛ وعند إضافة حسابات حقيقية يجب فرض عزل البيانات والتحقق من الصلاحيات على الخادم.

مساحة هدوء أداة للتوعية وتنظيم الأفكار وتخفيف التوتر، وليست بديلاً عن الطبيب أو المختص النفسي. عند الضغط الشديد، تواصل مع شخص موثوق أو مختص مناسب؛ الموقع ليس خدمة طوارئ.

## ملفات المشروع

- `index.html` — بنية الواجهة وإمكانية الوصول.
- `styles.css` — الهوية المرئية والتجاوب والمظهران الفاتح والداكن.
- `app.js` — التفاعلات، طبقة التخزين المحلية، التقييمات، اليوميات والرسوم.
